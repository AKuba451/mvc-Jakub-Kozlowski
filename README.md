# [ Ranking Gier Komputerowych ]

Projekt zaliczeniowy - Programowanie aplikacji internetowych MVC
Autor : [ Jakub Kozłowski ] , nr albumu [ 164785 ]

## Temat

Aplikacja która będzie rozwijana w moim projekcie to Ranking Gier Komputerowych. Użytkownicy będą mogli rejestrować się, logować oraz oceniać gry komputerowe według skali 1-5 gwiazdek w kilku kategoriach.

## Struktura repozytorium
- czesc1-servlet-jsp - aplikacja Servlet + JSP + JSTL (Tomcat 10.1)
- czesc2-spring-boot - aplikacja Spring Boot + Thymeleaf
- docs - dokumentacja projektu
